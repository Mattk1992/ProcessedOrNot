# Assets Directory

This directory contains the app assets like icons and splash screens.

## Required Assets

The following assets are needed for the mobile app:

- `icon.png` (1024x1024) - App icon
- `adaptive-icon.png` (1024x1024) - Android adaptive icon
- `favicon.png` (32x32) - Web favicon  
- `splash.png` (1284x2778) - Splash screen

## Placeholder Assets

For development purposes, you can use placeholder assets:
- Simple colored squares with app branding
- Use the brand colors from the main website
- Ensure proper dimensions for each platform

## Asset Generation

You can generate proper assets using:
- Adobe Illustrator or Photoshop
- Online icon generators
- Expo's asset generation tools
- Figma with proper export settings

The main website uses a blue primary color (#3B82F6) which should be reflected in the app assets.
